### [CareerFlow](https://github.com/Oleksandrnie/CareerFlow)

A local application for organizing a job search. Users add their own vacancies and collect job descriptions, CV versions, notes, attachments, and interview events for each one.

- Master Resume and vacancy-specific CV versions with provenance and version history, including a marker for the version actually submitted.
- Built-in Codex CLI integration: run a preset or custom prompt from the interface with context from the vacancy, CV, and added materials.
- Heuristic comparison of a CV against job requirements, application pipeline history, analytics, and Markdown reports.
- Separate storage of AI results and explicit creation of a new CV version by the user; checks that context matches the current versions of its sources.

**My contribution:** the full development cycle with AI assistance — from the idea and user scenarios to implementation, testing, and improvements.

**Stack:** Python, FastAPI, SQLite, vanilla JavaScript, HTML/CSS, Codex CLI.

[Code, documentation, and setup](https://github.com/Oleksandrnie/CareerFlow/blob/main/README.md)
