## Мои продукты

### [LocalGPT](https://github.com/Oleksandrnie/LocalGPT)

Локальное приложение для чата с AI-моделями и обработки информации: от аудиозаписи или документа до саммари, задач и ответа с контекстом.

- Чат с text/vision-моделями через Ollama, каталог моделей и Auto / Smart Router для выбора модели по запросу.
- Транскрибация аудио и пайплайн обработки результата: саммари, выделение задач и работа с контекстом транскрипта.
- RAG с базами знаний по профилям, OCR изображений и озвучка через Piper.
- Streaming с возможностью отключения, управление режимом размышления по метаданным модели, адаптивный интерфейс и перенос моделей между установками.

**Мой вклад:** полный цикл создания продукта с ИИ — идея, требования, реализация, дизайн интерфейса, тестирование и развитие.

**Стек:** Python, FastAPI, SQLite, HTML/CSS/JavaScript, Ollama, whisper.cpp / faster-whisper, Piper, Tesseract.

[Код, документация и запуск](https://github.com/Oleksandrnie/LocalGPT/blob/dev/README.md)

### [CareerFlow](https://github.com/Oleksandrnie/CareerFlow)

Локальное приложение для организации поиска работы. Пользователь добавляет вакансии и собирает по каждой описание, версии CV, заметки, вложения и события интервью.

- Master Resume и версии CV под вакансии с сохранением происхождения и истории, включая отметку отправленной версии.
- Встроенный Codex CLI: запуск из интерфейса с готовым или собственным промптом и контекстом вакансии, резюме и добавленных материалов.
- Эвристическое сопоставление CV с требованиями вакансии, история переходов по воронке, аналитика и Markdown-отчёты.
- Отдельное сохранение AI-результатов и явное создание новой версии CV пользователем; проверка соответствия контекста текущим версиям источников.

**Мой вклад:** полный цикл разработки с ИИ — от идеи и сценариев до реализации, тестирования и доработок.

**Стек:** Python, FastAPI, SQLite, vanilla JavaScript, HTML/CSS, Codex CLI.

[Код, документация и запуск](https://github.com/Oleksandrnie/CareerFlow/blob/main/README.ru.md)
